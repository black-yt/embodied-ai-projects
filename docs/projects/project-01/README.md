# 双臂精细操作

项目研究机器人如何根据多视角图像和自然语言指令，协调双臂、对准工具，并完成可以独立训练、执行和评测的精细技能。以细胞培养实验中的移液和吹打作为真机评测场景。[查看项目展示页](index.html)。

## 模型

- **世界动作模型（World Action Model）**根据视觉和动作历史预测下一帧画面与动作片段。异步执行时，FDM 根据当前动作前瞻未来视觉特征，为下一段动作提供条件。实测画面用于校正后续预测的历史。
- **视觉语言动作模型（VLA）**把同步的头部、左腕和右腕图像与文本指令映射为双臂、手指和夹爪动作。执行后根据新观测继续预测。

## 工程经验

- **长静止筛查**。滑动窗口统计机器人状态各通道的活动范围。长暂停筛查可剔除低质量示教，帧级裁剪应保留按压等有效停顿。
- **原子动作切分与采样**。保留完整动作核心，在核实边界内各取 2–6 帧首尾上下文，并以 1∶1∶1 平衡首轮、中间轮和末轮。训练和验证按原始完整示教划分。
- **约束最小 jerk 平滑**。惩罚末端路径的三阶差分，固定实测起点和规划终点，限制对预测路径的偏移，并保留手部控制指令。
- **异步前瞻**。当前动作执行时，用 FDM 预测未来观测并提前计算下一段动作，减少动作窗口交接时的等待。
- **末端与关节空间**。EE 输出目标末端位姿，Joint 输出目标关节角。用 IK 将末端目标转为关节角，用 FK 将关节角转回末端位姿。在一致的参考系和关节解分支中，两种输出可以表示同一条轨迹。

## 数据与真机评测

示教库包含 **3,507 条完整轨迹**，覆盖 12 个任务的训练与验证划分。按同步帧数和 30 Hz 估算，总时长约 **2,500 分钟**。

六个独立技能在同一台双臂机器人上完成单次动作测试。共 **55 条记录、51 条成功、4 条失败，成功率为 92.7%**。

| 动作 | 真机成功数 / 记录数 |
| --- | ---: |
| 01 试管至培养皿 · 布置 A | 5/5 |
| 02 试管至培养皿 · 布置 B | 3/4 |
| 03 培养皿至试管 | 14/16 |
| 04 试管 A 至试管 B | 10/11 |
| 05 斜皿吹打 | 9/9 |
| 06 试管内吹打 | 10/10 |

四次失败中，一次发生在源容器吸液时，三次发生在目标试管口对准时。斜皿吹打中有两条循环边界不清，经操作员复核计为成功。以上结果基于录像判定，转移体积与混匀效果未在本轮量化。展示页可查看任意一轮的三路录像及失败判定。
